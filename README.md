# Bài kiểm tra giữa kỳ — CSE122

- **Tên đề tài:** InvoicePilot – Theo dõi hóa đơn và công nợ
- **Tên trang:** Bảng điều khiển – Quản lý
- **Họ và tên:** Nguyễn Ngọc Lâm
- **Mã sinh viên:** 2551060645

## Mục đích
Quản lý xem số liệu tổng quan, theo dõi hóa đơn quá hạn và xem dự báo dòng tiền.

## Chức năng
- Hiển thị 4 thẻ số liệu chính
- Bảng danh sách hóa đơn quá hạn tự động hiện
- Nhấn nút xem dự báo AI
- Hiển thị tốt trên máy tính và điện thoại

## Công nghệ
- HTML5 ngữ nghĩa
- CSS3 + Grid + Media Query
- Vanilla JavaScript
